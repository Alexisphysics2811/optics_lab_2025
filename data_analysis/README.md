# Data Analysis

This directory contains general-purpose data analysis scripts and tools used across multiple experiments.

## Purpose

Store reusable analysis functions and scripts here, such as:
- Curve fitting utilities
- Statistical analysis tools
- Signal processing functions
- Data cleaning and preprocessing scripts

## Usage

Import these utilities in your experiment scripts:
```python
from data_analysis.fitting import gaussian_fit
from data_analysis.processing import smooth_data
```
