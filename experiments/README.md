# Experiments

This directory contains Python scripts for individual optics laboratory experiments.

## Structure

Each experiment should be organized in its own subdirectory or as a standalone script, depending on complexity.

### Suggested naming convention:
- `exp_01_introduction.py` - For simple single-file experiments
- `exp_02_interference/` - For more complex experiments with multiple files

## Example structure for a complex experiment:
```
exp_02_interference/
├── main.py           # Main experimental script
├── analysis.py       # Data analysis functions
├── plotting.py       # Visualization functions
└── README.md         # Experiment-specific documentation
```
