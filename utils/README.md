# Utilities

This directory contains utility functions and helper scripts used throughout the project.

## Purpose

Store general-purpose utilities here, such as:
- File I/O helpers
- Unit conversion functions
- Plotting style configurations
- Common constants (wavelengths, physical constants, etc.)
- Equipment interface utilities

## Example

```python
from utils.constants import WAVELENGTH_RED_LASER
from utils.plotting import set_scientific_style
from utils.file_io import load_experiment_data
```
